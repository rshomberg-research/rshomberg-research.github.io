sidescanpy.grids.raster#

SideScanGriddedRaster: xarray-validated wrapper for gridded backscatter.

A raster is a GridDefinition + 2D backscatter array with xarray schema.

to_dataset()#

This raster as a plain xr.Dataset on 1-D cell-center axes.

Dims ("y", "x") with 1-D y/x coordinates (northing/ easting in metres for a projected CRS, latitude/longitude in degrees for a geographic one), in this raster’s own row order (south to north). Every data variable of dataset (backscatter, plus n_contributing_samples when present) is carried over with its attrs, and the CRS is stored CF-style in a scalar spatial_ref coordinate (crs_wkt / spatial_ref attrs, referenced from each variable’s grid_mapping), which rioxarray, GDAL and most CF readers recognize. Needs no optional dependency.

The grid’s cell centers are evenly spaced but, because GridDefinition stretches ceil(extent / resolution_m) cells across the bbox (a ratio within float error of a whole number counts as that number), the spacing is only approximately resolution_m (exactly it when the extent is a whole number of cells); x/y hold the real centers.

reproject_to(target_crs)#

Reproject raster to a different CRS.

Parameters:
target_crspyproj.CRS

Target coordinate reference system.

Returns:
SideScanGriddedRaster

New raster in target CRS. Backscatter data preserved (grid bounds transformed).

Notes

This reprojects the grid definition; backscatter values are not resampled. Use resample_channel_to_grid() for resampling. Grid cell count may change slightly due to extent changes; backscatter shape is preserved.
