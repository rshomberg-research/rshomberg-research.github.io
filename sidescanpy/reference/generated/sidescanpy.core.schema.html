sidescanpy.core.schema#

Schema validation and xr.Accessor for SideScanPy standard HDF5 format

This module defines the .ss.h5 (standardized SideScan HDF5) contract that all datasets must conform to. It provides validation via xr.Accessor and utilities for tracking processing state.

2026 rshomberg@uri.edu

class sidescanpy.core.schema.SideScanAccessor(ds)#

Bases: object

xarray.Dataset accessor for sidescan specific validation and utilities

Provides methods to validate datasets against the SideScanPy schema, track processing state, and compute derived quantities like slant range.

Accessed via ds.sidescan on any xarray.Dataset

Examples

>>> import xarray as xr
>>> ds = xr.Dataset(...)
>>> ds.sidescan.validate()  # Raises ValueError if invalid
>>> ds.sidescan.is_valid()  # Returns bool
>>> ds.sidescan.processing_level  # Returns str
validate()#

Validate dataset against SideScanPy schema.

Checks (in order):

  1. All required dimensions present and channel size == 2

  2. All required coordinates present

  3. All required variables present

  4. All required attributes present

  5. A legacy processing_level attribute, if present, holds a legacy value (raw/radiometric)

Raises:
ValueError

On first schema violation with specific, actionable message.

Examples

>>> ds.sidescan.validate()  # Raises if invalid, returns None if valid
is_valid()#

Check if dataset is valid without raising.

Returns:
bool

True if dataset passes all validations, False otherwise.

Examples

>>> if ds.sidescan.is_valid():
...     process(ds)
property processing_level#

Current processing level, derived from processing_history.

See sidescanpy.core.history.processing_level().

property processing_history#

Parse and return processing history.

Parses JSON from ds.attrs['processing_history'] into a list of dictionaries. Each entry has keys: - ‘step’: str, name of processing step - ‘timestamp_utc’: str, ISO 8601 timestamp - ‘params’: dict, parameters used in step - ‘function’: str, fully qualified function name - ‘version’: str, semantic version of function

Returns:
list of dict

Processing history entries, or empty list if missing/malformed.

Examples

>>> history = ds.sidescan.processing_history
>>> for entry in history:
...     print(f"{entry['step']} at {entry['timestamp_utc']}")
append_to_history(step_name, function_name, params, version)#

Append an entry to processing history.

Creates a new history entry with current timestamp and updates ds.attrs['processing_history'] as JSON string. Preserves all prior entries (append-only).

Parameters:
step_namestr

Name of processing step (e.g., ‘tvg_correction’).

function_namestr

Fully qualified function name (e.g., ‘sidescanpy.processing.radiometric.apply_tvg’).

paramsdict

Parameters used in this step. Can be any JSON-serializable dict.

versionstr

Semantic version of the function (e.g., ‘0.2.0’).

Examples

>>> ds.sidescan.append_to_history(
...     step_name='tvg_correction',
...     function_name='sidescanpy.processing.radiometric.apply_tvg',
...     params={'slope_db_per_m': 30.0, 'offset_db': 20.0},
...     version='0.2.0',
... )

class sidescanpy.core.schema.NavigationRecordAccessor(ds)#

Bases: object

xarray.Dataset accessor for navigation auxiliary streams.

A navigation record is a time series of position fixes, typically extracted from NMEA messages (RMC, GLL, GGA) or fallback-extracted from per-ping embedded fields. Stored as separate aux stream so it can be re-interpolated onto ping times later.

Required dims: {obs} Required coords: {time} (datetime64[ns]) Required vars: {latitude, longitude} Optional vars: heading_deg, speed_knots, course_deg Required attrs: {source}

Examples

>>> nav.navigation_record.validate()
>>> nav.navigation_record.is_empty()

class sidescanpy.core.schema.AttitudeRecordAccessor(ds)#

Bases: object

Auxiliary stream for attitude data (roll, pitch, heave).

Typically sourced from PitchRollDataMessage (JSF type 2020) or XTF ping headers.

Required dims: {obs} Required coords: {time} (datetime64[ns], same timebase as ping times) Required vars: {roll_deg, pitch_deg, heave_m} Optional vars: heading_deg (compass bearing, degrees clockwise from north), yaw_deg, temperature_c Required attrs: {source}

A NaN value marks a reading the source flagged invalid or did not carry.
