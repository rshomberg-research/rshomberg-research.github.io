    sidescanpy.grids.definition¶

    GridDefinition: metadata contract for a georeferenced grid.

    Defines bounding box, resolution, and projection. Handles CRS conversion. No data — just the schema/contract.

    GridDefinition ¶

    Georeferenced grid schema.

    A grid is defined by: - bbox: (south, west, north, east) in the given CRS - resolution_m: pixel size in meters - crs: pyproj.CRS (default WGS84)

    Provides derived properties (cell counts, coordinates) and projection helpers (reproject_to).

    extent_m_ew: float

    get_grid_centers ¶

    get_grid_centers() -> Tuple[np.ndarray, np.ndarray]

    Generate 2D arrays of grid cell center coordinates.

    Returns:

    Name Type Description
    lats ndarray of shape (num_cells_ns, num_cells_ew)
    lons ndarray of shape (num_cells_ns, num_cells_ew)

    Grid center coordinates in the CRS.
    Notes

    For WGS84, returns lat/lon. For projected CRS, returns northing/easting (but named as lats/lons for consistency).

    utm_crs_for_lonlat ¶

    utm_crs_for_lonlat(lon: float, lat: float) -> CRS

    Pick the WGS84 UTM zone CRS containing (lon, lat).

    Standard "auto-UTM" heuristic: zone = floor((lon + 180) / 6) + 1, hemisphere from the sign of lat. EPSG 326xx for northern- hemisphere zones, 327xx for southern. Good enough to pick a sane projected CRS automatically for a survey's gridded output; near a zone boundary (every 6° of longitude) the "correct" zone is a judgment call anyway — pass an explicit CRS via GridDefinition if a specific zone/datum is required (e.g. matching a state-plane system already in use for a project).

    Parameters:

    Name Type Description Default
    lon float

    WGS84 degrees. Typically the center of the survey's bbox.

    		 required
    lat float

    WGS84 degrees. Typically the center of the survey's bbox.

    		 required

    Returns:

    Type Description
    CRS

    WGS84 / UTM zone CRS (EPSG 32601-32660 or 32701-32760).

    utm_grid_from_wgs84_bbox ¶

    utm_grid_from_wgs84_bbox(
    bbox: Tuple[float, float, float, float],
    resolution_m: float,
) -> GridDefinition

    Build a GridDefinition in an auto-selected UTM zone from a WGS84 bbox.

    Picks the UTM zone containing the bbox's center point (via utm_crs_for_lonlat), then reprojects the bbox into that zone's meters via GridDefinition.reproject_to (dense edge sampling, not just 4 corners, for accuracy).

    Parameters:

    Name Type Description Default
    bbox (south, west, north, east)

    WGS84 degrees.

    		 required
    resolution_m float

    Grid cell size in meters.

    		 required

    Returns:

    Type Description
    GridDefinition

    Projected (UTM) grid covering the same ground area as bbox.

    bbox_from_channel_dataset ¶

    bbox_from_channel_dataset(
    ds,
    margin_frac: float = 0.1,
    min_margin_m: float = 5.0,
    min_margin_deg: Optional[float] = None,
) -> Tuple[float, float, float, float]

    (south, west, north, east) bbox fit to a channel dataset's per-sample lat/lon extent, with a small margin so edge cells aren't clipped.

    Typically the first step before utm_grid_from_wgs84_bbox when auto-fitting a grid to a segment.

    Parameters:

    Name Type Description Default
    ds Dataset

    Must have latitude_per_sample/longitude_per_sample (i.e. already georeferenced via compute_georeferencing).

    		 required
    margin_frac float

    Fraction of the lat/lon extent added as margin on each side.

    		 0.1
    min_margin_m float

    Minimum margin on each side, in meters (converted to degrees at the data's latitude), for a near-zero-extent segment.

    		 5.0
    min_margin_deg float

    Minimum margin in degrees instead of min_margin_m. (Before 0.6.1 this was the only option, defaulting to 0.001 deg -- about 110 m, which dominated the margin of a typical grid segment.)

    		 None

    Returns:

    Type Description
    (south, west, north, east)

    Raises:

    Type Description
    ValueError

    If no finite latitude/longitude_per_sample values are present.
