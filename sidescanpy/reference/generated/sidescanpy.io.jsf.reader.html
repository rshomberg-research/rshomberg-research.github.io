sidescanpy.io.jsf.reader#

JSF file reading, parsing, and inspection utilities.

This module provides: 1. Parse JSF binary files into message objects (streaming or bulk) 2. Inspect and debug JSF messages (slice, filter, export) 3. Export messages to JSON or other formats for inspection

The module focuses on raw message access without intermediate formats. For analysis/conversion, use the converter module to transform to standard schema.

sidescanpy.io.jsf.reader.read_jsf(fpath, N=None)#

Parse all messages from a JSF binary file.

Reads JSF binary format and deserializes messages sequentially until end-of-file or limit reached. Each message is validated and deserialized.

Parameters:
fpathPath

Path to JSF binary file.

Nint, optional

Maximum number of messages to read. If None (default), read all.

Returns:
list[JSFMessage]

List of parsed message objects in order.

Raises:
FileNotFoundError

If JSF file does not exist.

Examples

>>> messages = read_jsf(Path("survey.jsf"))
>>> print(f"Read {len(messages)} messages")

>>> # Read first 1000 messages only
>>> messages = read_jsf(Path("survey.jsf"), N=1000)
sidescanpy.io.jsf.reader.read_jsf_iter(fpath)#

Parse messages from JSF file as generator (memory efficient).

Yields messages one at a time instead of loading entire file into memory. Useful for processing large JSF files or streaming to HDF5.

Parameters:
fpathPath

Path to JSF binary file.

Yields:
JSFMessage

Next parsed message object.

Raises:
FileNotFoundError

If JSF file does not exist.

Examples

>>> for message in read_jsf_iter(Path("survey.jsf")):
...     print(type(message).__name__)
...     if isinstance(message, SonarDataMessage):
...         process_sonar(message)
sidescanpy.io.jsf.reader.get_messages_by_index(fpath, start_idx=0, end_idx=None)#

Retrieve JSF messages by index range (slicing).

Efficiently reads a specific range of messages from JSF file without loading entire file. Useful for debugging or inspecting specific regions.

Parameters:
fpathPath

Path to JSF binary file.

start_idxint

Starting message index (0-indexed). Default: 0

end_idxint, optional

Ending message index (exclusive). If None, read to end of file.

Returns:
list[JSFMessage]

Messages in the specified range.

Examples

>>> # Get messages 100-150
>>> messages = get_messages_by_index(Path("survey.jsf"), 100, 150)

>>> # Get first 50 messages
>>> messages = get_messages_by_index(Path("survey.jsf"), 0, 50)

sidescanpy.io.jsf.reader.export_messages_to_json(messages, output_path, pretty=True, max_messages=None)#

Export messages to JSON for inspection/debugging.

Creates a JSON file with all messages. Large numpy arrays are summarized to keep file size reasonable. Useful for inspecting message structure and debugging conversion issues.

Parameters:
messageslist[JSFMessage]

Messages to export.

output_pathPath

Output JSON file path.

prettybool

If True (default), use indentation for readability.

max_messagesint, optional

Maximum messages to export. If None, export all.

Examples

>>> messages = read_jsf(Path("survey.jsf"), N=100)
>>> export_messages_to_json(messages, Path("debug.json"))

>>> # Export only sonar messages
>>> sonar_msgs = filter_messages_by_type(messages, 'SonarDataMessage')
>>> export_messages_to_json(sonar_msgs, Path("sonar_debug.json"), max_messages=50)
