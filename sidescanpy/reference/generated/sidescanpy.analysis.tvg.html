sidescanpy.analysis.tvg#

TVG analysis: backscatter-vs-range profiles and hardware-TVG detection.

The TVG fit is sidescanpy.analysis.fit_tvg_models() (in sidescanpy.analysis.tvg_fit). The candidate classifier below, fit_range_decay() and fit_tvg_curve() with TVGCandidateFit and TVGCandidateFitResult, is deprecated since 0.10 and will be removed in 0.12: it anchored every model at one reference bin, compared one spreading coefficient at a time and took its window from the nadir and usable-range analyses, which often left it fitting the wrong stretch of range.

Profiles and comparisons:

  • backscatter_vs_range(), backscatter_vs_sample() — binned statistics (re-exported from sidescanpy.processing.profiles).

  • compare_before_after() — raw vs. TVG-corrected dB and the applied gain, side by side.

  • bin_by_altitude() — split pings into equal-count altitude bins.

Detecting what TVG the data already carries:

  • fit_tvg_curve() — fit four single-term candidate loss models (flat, spreading_only, absorption_only, full_physics) to an observed loss-vs-range curve (TVGCandidateFitResult).

  • fit_range_decay() — bin a dataset, fit the candidates and classify which terms hardware has already removed (RangeDecayResult).

class sidescanpy.analysis.tvg.TVGCandidateFit(name, params, scale, rmse_db, fixed_scale_rmse_db, r_ref_m, r_fit_max_m, n_bins_used, r_fit_min_m=None)#

Bases: object

One candidate loss model fit against an observed loss-vs-range curve.

scale is the least-squares multiplier on the candidate’s model (near 1: the data decays like that model as written; near 0: that term is essentially absent) and rmse_db its residual. fixed_scale_rmse_db is the residual with the scale pinned to 1 — the literal physics model. Candidates are ranked by the fixed-scale value, because a free scale on one term can absorb unrelated range-dependent effects and win on RMSE alone. For flat (model identically zero) both values are equal.

Deprecated since version 0.10: Removed in 0.12; see TVGModelFit.

sidescanpy.analysis.tvg.fit_tvg_curve(binned, *, spreading_loss_db=30.0, absorption_db_per_m, r_ref_m=None, r_fit_min_m=None, r_fit_max_m=None, min_count_for_r_ref=30, fit_fraction=0.6, r_ref_search_fraction=0.5, value_col='mean')#

Fit four candidate hardware-TVG models to a binned raw dB-vs-range curve.

Deprecated since version 0.10: Removed in 0.12. Use fit_tvg_models(), which fits a free constant, compares 20/30/40 log R with and without absorption, and ends its window at the noise knee.

Each candidate is a term (or both) of tvg_gain_db() still present in the data:

  • flat — neither term (hardware compensated both)

  • spreading_only — only spreading_loss_db * log10(R)

  • absorption_only — only 2 * absorption_db_per_m * R

  • full_physics — both (no hardware compensation)

The fitted quantity is observed_loss(r) = value[r_ref] - value[r] (absolute level is unknown). Each candidate gets one free scale, fitted independently: a joint two-term regression is poorly conditioned because the terms are nearly collinear over realistic range spans.

Parameters:
binnedpd.DataFrame

backscatter_vs_range() output computed on uncorrected dB backscatter.

spreading_loss_dbfloat, default 30.0

Spreading coefficient of the spreading_only and full_physics candidates (DEFAULT_SPREADING_LOSS_DB).

absorption_db_per_mfloat

Required; pass the survey’s own frequency-appropriate value.

r_ref_mfloat, optional

Reference range. Default: the bin with the highest value among bins with count >= min_count_for_r_ref in the near r_ref_search_fraction of the range span (falls back to all eligible bins). Not simply the nearest bin, which often reads low from ring-down/blanking; not the global max, which on flat data can land on a far-range noise bump.

r_fit_min_mfloat, optional

Near edge of the fit window. Default r_ref_m (one-sided). Set it lower to fit both sides of the reference.

r_fit_max_mfloat, optional

Far edge of the fit window. Default r_ref_m + fit_fraction * (max_range - r_ref_m).

min_count_for_r_refint, default 30
fit_fractionfloat, default 0.6
r_ref_search_fractionfloat, default 0.5

Per-bin statistic to fit.

Bases:

TVG-status classification from a range-decay fit.

Deprecated since version 0.10: Removed in 0.12, with fit_range_decay(); see TVGFitResult.

tvg_status names what hardware has already removed: "none", "spreading_only", "absorption_only", "full", or "ambiguous" (winner not clearly ahead, or too little data). best_rmse_db is the winner’s fixed-scale RMSE (the ranking criterion); best_free_fit_* are its free-scale values. r_ref_m_override / r_fit_min_m_override record what was requested (e.g. "auto"); r_ref_m / r_fit_min_m what was used. With r_fit_min_m="auto" resolved, r_fit_min_auto_search_max_m is the bound of the near-field peak search (bin centers up to it) and r_fit_min_auto_peak_edge_m the peak bin’s far edge, so the resolved value is r_fit_min_auto_peak_edge_m + r_fit_min_auto_margin_m before any clamp to r_ref_m; it can lie past the search bound. fit (the full TVGCandidateFitResult) is left out of to_dict(); candidates summarizes it.

sidescanpy.analysis.tvg.fit_range_decay(ds, value_var='backscatter_intensity', range_var='slant_range_m', *, already_db=False, db_reference_percentile=99.0, db_reference_value=None, freq_hz=None, bin_width_m=5.0, usable_range_m=None, min_bins=6, ambiguous_rel_tol=0.2, min_total_count=30, exclude_before_sample=None, exclude_first_n_bins=0, reject_outliers=False, outlier_mad_k=3.5, outlier_min_bin_count=5, fit_value_col='mean', r_ref_m=None, r_fit_min_m=None, r_fit_min_auto_margin_m=5.0, r_ref_search_fraction=0.5, r_ref_window_fraction=0.3333333333333333, channel=None, spreading_loss_db=30.0)#

Classify which TVG terms value_var already carries.

Deprecated since version 0.10: Removed in 0.12. Use fit_tvg_models() (and check_tvg()); its best model is the TVG to apply and its tvg_status replaces this one. This function anchors every model at one reference bin, compares one spreading coefficient at a time and needs its window from the caller, so its answers differ.

Converts to dB, bins by range_var, fits the four fit_tvg_curve() candidates and maps the winner (lowest fixed-scale RMSE) to a TVG status. If the runner-up’s RMSE is within ambiguous_rel_tol (relative) of the winner’s, the status is "ambiguous".

Water-column samples are always excluded via ground_range_m’s NaN pattern (when present), independent of range_var.

r_ref_mfloat, “auto”, “mid_swath” or None

Reference range. None: fit_tvg_curve()’s near-field auto-pick. "auto" (recommended with r_fit_min_m="auto"): placed r_ref_window_fraction of the way from the resolved fit window’s near edge to usable_range_m, so it always lies inside the window. "mid_swath" (legacy): usable_range_m / 2. Both string modes fall back to the auto-pick, with a note, when usable_range_m is unavailable.

r_fit_min_mfloat, “auto” or None

Near edge of the fit window (resolved before r_ref_m). None: one-sided from r_ref_m. "auto": the raw near-field peak bin’s far edge plus r_fit_min_auto_margin_m, searched up to a numeric r_ref_m or r_ref_search_fraction * usable_range_m; falls back to None with a note when it can’t be resolved. Only the peak is searched for within that bound: the margin, added afterwards, can carry the value past it, and the result reports both (r_fit_min_auto_search_max_m, r_fit_min_auto_peak_edge_m). If it ends up beyond a numeric/”mid_swath” r_ref_m it is clamped to it.

Spreading coefficient of the spreading_only and full_physics candidates; pass the value the survey’s correction uses.
