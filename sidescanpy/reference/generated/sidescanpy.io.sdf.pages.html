sidescanpy.io.sdf.pages#

Klein SDF page types and parser.

A Klein SDF file is a sequence of pages. Each page has: - A 4-byte sync marker (always 0xFFFFFFFF) - A 512-byte typed header (described by SDFPageHeader) - Variable-length data section (sonar samples for sonar page versions)

The header is a binary structure of 128 uint32-equivalent slots. Most fields are uint32 or float32 (4 bytes); seven fields are float64 (8 bytes, taking 2 slots). All values are little-endian.

Spec source: Klein SDF/SDFX Data Page Definitions Specification.

Conventions encoded here:

  • Latitude/longitude stored as float64 in radians; converted to degrees via @property

  • Heading/pitch/roll stored as float32 in degrees; no conversion

  • speedFish stored as cm/s; converted to m/s via @property

  • speedSound stored as cm/s; converted to m/s via @property

  • sonarFreq stored in kHz; converted to Hz via @property

  • Year normally 4-digit; older firmware uses offset-from-1900, auto-detected via < 200 check

  • Time fractional component (fseconds field 51) preferred over hSecond field 24 when both are valid

Klein SDF page header (512 bytes after the 4-byte marker).

All fields are little-endian. The dataclass holds the raw spec values; transformed (unit-converted) versions are exposed via @property.

Field numbers in comments correspond to the Klein spec table (1-100 named, 101-126 reserved). Fields prefixed with underscore are internal raw forms with corresponding public properties.

Note on uint16 fields (80-83): the spec says U16 but Klein stores them in 32-bit slots with values fitting in the lower 16 bits. They’re parsed as uint32 here for layout purity.

class sidescanpy.io.sdf.pages.SDFUnknownPage(header, body_bytes=b'')#

Bases: object

A parsed Klein SDF page of unknown/unsupported version.

The header is fully parsed (since all SDF pages share the same header structure), but the body is preserved as raw bytes for later analysis. Use the page version to identify what kind of page it is and decide whether to add typed parsing.

Attributes:
headerSDFPageHeader

Parsed page header (always valid).

body_bytesbytes

Raw body content (size = header.page_size - PAGE_HEADER_BYTES). Includes everything between the header and the next page’s marker.
