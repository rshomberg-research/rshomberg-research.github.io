Example data#

The examples and Getting started run on real, openly licensed recordings that anyone can download.

The example data#

sidescanpy.datasets.fetch(name) returns a local path to a recording, downloading it the first time. Each recording is one file inside a large public agency archive (8 to 57 GB); fetch reads just that file out of the archive with HTTP range requests, checks its SHA-256 and caches it.

from sidescanpy import datasets

datasets.list_datasets()          # the names fetch() accepts
path = datasets.fetch("usgs_grand_bay_150602205800.xtf")
print(datasets.citation("usgs_grand_bay_150602205800.xtf"))

Files are cached in ~/.cache/sidescanpy, or in SIDESCANPY_DATA_DIR when set. A file already there with the right checksum is used without going online.

The London Gateway files store navigation as UTM zone 31N easting and northing without saying so: convert them with nav_crs="EPSG:32631". They record no heading (use the course over ground), their samples already carry the recorder’s TVG, and their Weight fields are garbage, which the reader ignores with a warning. datasets.BGS_LONDON_GATEWAY_WRECKS holds the catalogued centre of each wreck from the BGS record (UTM 31N meters); a line can show its wreck tens of meters from that centre along track.
