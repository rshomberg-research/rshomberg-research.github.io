    sidescanpy.processing.bottom¶

    Nadir and first-bottom-return detection, and the masks built on them.

    Along each ping, a sidescan record runs through three zones: a leading nadir-noise burst (transmit ring-down; some hardware zeros it before writing the file, some doesn't), a quiet span the beam never illuminates, and the real bottom return. The functions here find those boundaries per (ping, channel) and blank or mask the data before them.

    • :func:detect_nadir_noise_extent / :func:blank_nadir_noise — find and zero the leading noise burst (a processing step).
    • :func:detect_first_bottom_return — amplitude-based onset of the real bottom return, optionally floored at the altitude sample.
    • :func:smooth_boundary_across_pings — rolling median of a per-ping boundary.
    • :func:uniform_exclusion_boundary — collapse a per-ping boundary to one conservative value for aggregate binning.
    • :func:mask_nadir_gap — NaN everything before the first bottom return (display/export copy).
    • :func:mask_before_sample, :func:altitude_sample_index — helpers.
    • :func:altitude_from_bottom_track — fill missing altitude_m from the first bottom return (the "bottom_track" correction step).

    All detectors are vectorized over (ping, channel, sample) arrays and return (ping, channel) float sample indices (NaN = not found).

    BOTTOM_TRACK_REPLACE module-attribute ¶

    BOTTOM_TRACK_REPLACE = ('missing', 'all')

    Accepted replace values of :func:altitude_from_bottom_track.

    detect_first_bottom_return ¶

    detect_first_bottom_return(
    value_arr: ndarray,
    *,
    smooth_window: int = 10,
    threshold_fraction: float = 0.2,
    min_run: int = 10,
    min_sample: ndarray | float | None = None,
    min_sample_buffer: float = 0.0,
    peak_percentile: float = 100.0,
    min_run_fraction: float = 1.0,
) -> np.ndarray

    Per-(ping, channel) sample index where the real bottom return starts.

    Smooths each ping with a smooth_window-sample rolling mean, then finds the first point where the smoothed value stays at or above threshold_fraction of that ping's own peak for min_run consecutive samples. The threshold is relative per ping and channel, since amplitude scale varies by channel and survey.

    This is not the altitude crossing (slant_range_m > altitude_m): a real beam's near edge is tilted away from vertical, so the first bottom return lands further out than altitude alone predicts.

    Parameters:

    Name Type Description Default
    value_arr ndarray

    (ping, channel, sample) linear amplitude (not dB).

    		 required
    smooth_window int
    		10
    threshold_fraction float

    Fraction of the ping's peak smoothed value.

    		 0.2
    min_run int

    Samples the rise must be sustained for.

    		 10
    min_sample array - like or float

    Per-(ping, channel) or scalar floor. Samples before it are ignored for both the peak and the onset search. Normally the altitude sample: the bottom can't return before it. NaN entries mean "no floor" for that row.

    		 None
    min_sample_buffer float

    Added to min_sample before use, to step past residual near-nadir noise.

    		 0.0
    peak_percentile float

    Percentile of the smoothed values used as the peak reference (100 = max). Lower it to stop one bright residual sample from setting the threshold.

    		 100.0
    min_run_fraction float

    Fraction of the min_run samples that must be at or above the threshold (the onset sample itself always must be). Below 1 a long run tolerates gaps, such as shadows in a rough seabed return.

    		 1.0

    Returns:

    Type Description
    ndarray

    (ping, channel) float sample index, NaN where no sustained rise was found. Accurate to about smooth_window samples.

    smooth_boundary_across_pings ¶

    smooth_boundary_across_pings(
    boundary: ndarray, *, window: int = 15
) -> np.ndarray

    NaN-aware rolling median of a (ping, channel) boundary along pings.

    Per-ping detection is independent, so occasional pings jump far from their neighbours. A median (not mean) removes those without smearing real multi-ping trends.

    Parameters:

    Name Type Description Default
    boundary ndarray

    (ping, channel).

    		 required
    window int

    Window in pings, centred; an even value is bumped up by one.

    		 15

    Returns:

    Type Description
    ndarray

    Same shape. A ping whose whole window is NaN stays NaN.

    detect_nadir_noise_extent ¶

    detect_nadir_noise_extent(
    value_arr: ndarray,
    *,
    search_window: int = 100,
    smooth_window: int = 5,
    threshold_fraction: float = 0.2,
    min_run: int = 10,
    margin_samples: int = 0,
    min_extent_samples: float = 0.0,
) -> np.ndarray

    Per-(ping, channel) sample index where the leading nadir-noise burst ends.

    Mirror image of :func:detect_first_bottom_return: finds where an initially strong signal falls to a sustained low level. Some hardware (e.g. EdgeTech JSF) zeros this burst before writing the file; others (e.g. Klein SDF) leave it in, where it can fool the first-bottom-return detector.

    Parameters:

    Name Type Description Default
    value_arr ndarray

    (ping, channel, sample) linear amplitude.

    		 required
    search_window int

    Only the first search_window samples set the burst's peak reference, so a bright bottom return further out can't inflate the threshold.

    		 100
    smooth_window int

    As in :func:detect_first_bottom_return, applied to a fall below the threshold.

    		 5
    threshold_fraction int

    As in :func:detect_first_bottom_return, applied to a fall below the threshold.

    		 5
    min_run int

    As in :func:detect_first_bottom_return, applied to a fall below the threshold.

    		 5
    margin_samples int

    Added to each detected extent (NaN rows stay NaN).

    		 0
    min_extent_samples float

    Hard floor on the result, applied last; unlike margin_samples it also replaces NaN rows.

    		 0.0

    Returns:

    Type Description
    ndarray

    (ping, channel) float sample index. 0 where the leading samples are already quiet. NaN for pings too short to evaluate or with no sustained drop (unless min_extent_samples is set).

    blank_nadir_noise ¶

    blank_nadir_noise(
    ds: Dataset,
    *,
    value_vars: tuple[str, ...] = (
        "backscatter_intensity",
    ),
    detector_value_var: str = "backscatter_intensity",
    search_window: int = 100,
    smooth_window: int = 5,
    threshold_fraction: float = 0.2,
    min_run: int = 10,
    margin_samples: int = 0,
    min_extent_samples: float = 0.0,
) -> xr.Dataset

    Return a copy of ds with each ping's leading nadir-noise burst set to 0.

    Uses :func:detect_nadir_noise_extent on detector_value_var and zeros the same span in every value_vars entry present in ds (others are skipped). A no-op where the burst is already zero. Contrast :func:mask_nadir_gap, which NaNs the much larger span out to the first bottom return for display.

    The remaining parameters are passed to :func:detect_nadir_noise_extent.

    uniform_exclusion_boundary ¶

    uniform_exclusion_boundary(
    per_ping_boundary: ndarray, percentile: float = 90.0
) -> np.ndarray

    Collapse a per-(ping, channel) boundary to one conservative value.

    For aggregate range binning, a per-ping boundary biases the near bins: only the pings whose boundary is earliest (usually the shallowest, brightest ones) contribute there. A single cutoff keeps every bin's contributing pings the same.

    		 required
    percentile float

    Percentile across all finite entries.

    		 90.0

    Returns:

    Type Description
    ndarray

    Same shape, filled with that one value; all-NaN if the input has no finite entries.

    altitude_from_bottom_track ¶

    altitude_from_bottom_track(
    ds: Dataset,
    *,
    replace: str = "missing",
    max_diff_m: float | None = None,
    min_altitude_m: float = 0.5,
    min_return_m: float = 5.0,
    min_return_fraction: float = 0.7,
    smooth_window: int = 10,
    threshold_fraction: float = 0.2,
    min_run: int = 10,
    smooth_pings: int = 1,
) -> xr.Dataset

    Set altitude_m from the first bottom return (the "bottom_track" step).

    Many recordings carry no usable altitude: no altimeter, no bottom lock, or a recorder that writes 0. Without it the geometric step cannot compute ground range (NaN altitude) or computes it as if the towfish sat on the seabed (altitude 0). This step measures altitude from the data instead: per ping and channel, the onset of the bottom return (:func:detect_first_bottom_return on the uncorrected amplitude, refined to the first sample reaching half the return level that follows it, since the detector's rolling mean fires up to smooth_window samples early), the nearer of the two channels, converted to metres of slant range.

    The first return comes from the beam's near edge, which is tilted away from vertical, so on sloping or rough seabed the tracked value is the slant range to the nearest bottom point, at or slightly above the true altitude. Recorded altitude, when valid, is the better value; the default only fills pings that lack it.

    Parameters:

    Name Type Description Default
    ds Dataset

    One frequency channel. Radiometric steps already applied are undone for detection only; backscatter_intensity is not changed.

    		 required
    replace (missing, all)

    "missing": replace pings whose altitude_m is NaN or <= 0. "all": replace every ping with a detection.

    		 "missing"
    max_diff_m float

    With "missing", also replace pings whose recorded altitude differs from the tracked one by more than this (a lost bottom lock that still writes a value).

    		 None
    min_altitude_m float

    Detection ignores samples nearer than this.

    		 0.5
    min_return_m float

    Slant distance the return must stay above threshold, converted to samples and used as the detector's min_run when longer. A transmit burst (some recorders keep it; it can start after a quiet lead-in and be as bright as the seabed) lasts a metre or two; the seabed return lasts tens of metres.

    		 5.0
    min_return_fraction float

    Fraction of that distance that must be above threshold (min_run_fraction of the detector), so shadows and gaps in a rough seabed return do not push the onset further out.

    		 0.7
    smooth_window int

    Passed to :func:detect_first_bottom_return (min_run in samples, raised to min_return_m when that is longer).

    		 10
    threshold_fraction int

    Passed to :func:detect_first_bottom_return (min_run in samples, raised to min_return_m when that is longer).

    		 10
    min_run int

    Passed to :func:detect_first_bottom_return (min_run in samples, raised to min_return_m when that is longer).

    		 10
    smooth_pings int

    Rolling median of the tracked altitude over this many pings (:func:smooth_boundary_across_pings); 1 = none. Smoothing looks across pings, so a chunked :func:~sidescanpy.processing.correct_file run can differ from an unchunked one within smooth_pings // 2 pings of each chunk edge.

    		 1

    Returns:

    Type Description
    Dataset

    ds with altitude_m replaced where selected and a "bottom_track" history record. Pings with no detection keep their recorded value. fathometer_reading_m is not changed.
