    sidescanpy.viz.tvg¶

    Plots for TVG and range-decay analysis (:mod:sidescanpy.analysis.tvg).

    Each function draws into an optional ax, returns (fig, ax) and never saves a file.

    2026 rshomberg@uri.edu

    plot_mean_vs_range ¶

    plot_mean_vs_range(
    binned: DataFrame,
    ax: Axes | None = None,
    *,
    show_band: bool = True,
    band: tuple[str, str] = ("p10", "p90"),
    label: str | None = None,
    color: str | None = None,
    linewidth: float = 1.5,
    zorder: float = 3.0,
    title: str | None = None,
) -> tuple[Figure, Axes]

    Line plot of mean backscatter vs. range, with an optional shaded percentile band.

    Call twice on the same ax (raw vs. corrected) for a direct before/after overlay.

    Parameters:

    Name Type Description Default
    binned DataFrame

    Output of backscatter_vs_range (or backscatter_vs_sample — any DataFrame with a "mean" column and matching min/max range columns).

    		 required
    show_band bool

    Shade the region between band's two percentile columns.

    		 True
    band (str, str)
    		("p10", "p90")
    linewidth float

    Matplotlib's own default is 1.5, so this default is a no-op for existing callers -- pass a larger value (e.g. when overlaying on top of plot_per_ping_profiles' dense low-alpha spaghetti, which can otherwise visually bury a thin mean line even with a distinct color) to make the mean line read clearly on top.

    		 1.5
    zorder float

    Matplotlib draws in call order by default (zorder 1, 2, 3, ... as each ax.plot/fill_between call happens) -- 3.0 is chosen to sit above a typical single prior plot_per_ping_profiles call (which doesn't set its own zorder, so defaults to 1) even if draw order alone wouldn't guarantee it. Raise further if overlaying on top of more layers.

    		 3.0

    plot_per_ping_profiles ¶

    plot_per_ping_profiles(
    ds: Dataset,
    value_var: str,
    range_var: str = "ground_range_m",
    n_pings: int = 50,
    ax: Axes | None = None,
    alpha: float = 0.08,
    *,
    channel_idx: int = 0,
    seed: int = 0,
    title: str | None = None,
    x_sign: float = 1.0,
) -> tuple[Figure, Axes]

    "Spaghetti plot": overlay n_pings individual ping profiles (value_var vs. range_var, one channel) at low alpha.

    Visual density shows ping-to-ping consistency/variance directly — complementary to plot_mean_vs_range's percentile band, which summarizes spread but averages away periodic per-ping artifacts.

    Parameters:

    Name Type Description Default
    channel_idx int

    Which channel to plot (0 = port, 1 = starboard per this schema's convention) — call twice with channel_idx=0 and channel_idx=1 on separate axes for a side-by-side port/ starboard comparison. Previously hardcoded to 0; the default preserves that exact behavior for existing callers.

    		 0
    x_sign float

    Multiplies every plotted range_var value before drawing — pass -1.0 (typically for channel_idx=0/port) to mirror one channel onto the negative side of a shared axis, so calling this twice (once per channel, opposite signs) on the same ax draws one continuous full-swath profile instead of two independent one-sided ones. range_var itself (e.g. slant_range_m) is always unsigned magnitude — this is a display-only sign flip, not a different range computation. 1.0 is a no-op, preserving every existing caller's output exactly.

    		 1.0

    plot_candidate_fit ¶

    plot_candidate_fit(
    fit: TVGCandidateFit,
    observed_range_m: ndarray,
    observed_loss_db: ndarray,
    ax: Axes | None = None,
    *,
    color: str | None = None,
    show_observed: bool = True,
    title: str | None = None,
    use_fixed_scale: bool = True,
    model_n_points: int = 200,
) -> tuple[Figure, Axes]

    Overlay one analysis.tvg.fit_tvg_curve() candidate's fitted model against the observed raw-loss curve it was fit against.

    Call once per candidate on the same ax (result.candidates from TVGCandidateFitResult) — show_observed=True on the first call only, False on the rest, so the observed curve is drawn once and each candidate's fitted line overlays it. Mirrors plot_mean_vs_range's existing "call twice for before/after" idiom, generalized to "call once per candidate."

    Parameters:

    Name Type Description Default
    fit TVGCandidateFit

    One candidate from TVGCandidateFitResult.candidates (or .best).

    		 required
    observed_range_m ndarray

    TVGCandidateFitResult.observed_range_m/.observed_loss_db — the same arrays for every candidate fit from one fit_tvg_curve() call, so passing a different candidate on repeated calls only changes the overlaid line.

    		 required
    observed_loss_db ndarray

    TVGCandidateFitResult.observed_range_m/.observed_loss_db — the same arrays for every candidate fit from one fit_tvg_curve() call, so passing a different candidate on repeated calls only changes the overlaid line.

    		 required
    show_observed bool

    Plot the observed curve itself. Set False on repeat calls against the same ax to avoid redrawing it once per candidate.

    		 True
    use_fixed_scale bool

    Draw the literal, uncalibrated model (scale pinned to 1.0) -- matches what fit_range_decay actually ranks candidates by (2026-08-24 change; see TVGCandidateFit's docstring). False draws the old free-fit-scaled line instead, for diagnostic comparison against the fixed-scale one -- e.g. to see by how much a candidate needed to cheat to look competitive.

    		 True
    model_n_points int

    The model line is drawn over its own dense, evenly-spaced range array from 0 to observed_range_m's max — not just at the bin centers observed_range_m happens to have — so the curve's shape reads smoothly all the way back to near-zero range for reference, including where no observed data exists (e.g. inside the excluded nadir gap). Purely a display domain; the fit itself was never evaluated there and this draws no new conclusion about that span.

    		 200

    plot_range_decay_fit(

    set_fit_window_limits ¶

    set_fit_window_limits(
    ax: Axes,
    result: RangeDecayResult,
    *,
    x_pad_fraction: float = 0.12,
    y_pad_fraction: float = 0.25,
    y_pad_min_db: float = 1.0,
    x_pad_min_m: float = 1.0,
) -> None

    Set robust axis limits on a decay-fit axis from the fit window.

    y-limits come from the observed values inside the fit window (result.r_fit_min_m..r_fit_max_m) only, so an out-of-window outlier bin cannot compress the fit curves. x-limits deliberately span 0 to the far edge (padded), not the fit window, so a misplaced reference or window stays visible. With a shared x-axis, call this on one panel only. No-op if there is no fit or no recorded window.

    plot_range_decay_residuals ¶

    plot_range_decay_residuals(
    result: RangeDecayResult,
    *,
    use_fixed_scale: bool = True,
    ax: Axes | None = None,
    relative_x: bool = True,
) -> tuple[Figure, Axes]

    Residual (model - observed) vs. range within each candidate's fit window.

    use_fixed_scale=True (default) draws the scale-1.0 residual and labels it with fixed_scale_rmse_db, the number candidates are ranked by; False draws the free-fit-scaled residual for comparison. The reference uses the nearest bin to r_ref_m, matching fit_tvg_curve's own RMSE computation exactly. relative_x=True plots distance from each candidate's r_ref_m; pass False for absolute range (to stack under :func:plot_candidate_fit on a shared x-axis).
