sidescanpy.io.jsf.messages#

jsf messages - define message types for jsf files

JSF files are from EdgeTech Side Scan Sonars. They are binary formatted and contain a series of messages. Each message starts with a header that contains basic information about the message.

Attitude sensor reading (JSF message type 2020).

Body layout per the EdgeTech JSF spec (44 bytes, little endian): int32 seconds since 1970, int32 milliseconds in the current second, 4 reserved bytes, int16 acceleration x/y/z (x 20*1.5/32768 G), int16 rate gyro x/y/z (x 500*1.5/32768 deg/s), int16 pitch and roll (x 180/32768 deg; bow up and port up positive), int16 temperature (0.1 degC), uint16 device-specific info, int16 heave (mm, positive down), uint16 heading (0.01 deg), int32 validity flags, int16 yaw (0.01 deg), int16 reserved.

A derived field is set only when its validity bit is set (bit 0-2 acceleration x/y/z, 3-5 rate x/y/z, 6 pitch, 7 roll, 8 heave, 9 heading, 10 temperature, 11 device info, 12 yaw); otherwise it stays None. Devices are known to clear bits for sensors they lack (for example heave and yaw) while setting pitch, roll and heading.

sidescanpy.io.jsf.messages.calculate_dvl_altitude_plane_fit(beam_distances, beam_angle=20.0)#

Calculate altitude, pitch, and roll from DVL 4-beam distances using plane fitting.

This method fits a plane to the 4 beam endpoints and extracts: - Altitude (vertical distance to the fitted plane) - Pitch (rotation about cross-track axis) - Roll (rotation about along-track axis)

DVL beams are typically arranged in a Janus configuration: - Beam 1: Forward-starboard (+x, +y) - Beam 2: Aft-starboard (-x, +y) - Beam 3: Aft-port (-x, -y) - Beam 4: Forward-port (+x, -y)
