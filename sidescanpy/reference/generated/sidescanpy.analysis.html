sidescanpy.analysis#

Quantitative analysis tools for sidescan data.

Each function takes data and returns a result dataclass (with to_dict()); none runs a workflow or plots (see sidescanpy.viz.analysis and sidescanpy.viz.tvg).

  • characterize_values() / infer_units() — value-range summary and units call (ValueSummary, UnitsResult).

  • compare_outlier_rejection() — effect of range-binned outlier rejection (OutlierComparisonResult).

  • analyze_nadir() — nadir type, altitude and first-bottom-return boundaries (NadirResult).

  • estimate_beam_geometry() — near/far beam edges (BeamGeometryResult).

  • estimate_usable_range() — where signal falls to the noise floor (UsableRangeResult).

  • fit_range_decay() — TVG-status classification from a range-decay fit (RangeDecayResult); fit_tvg_curve(), compare_before_after(), bin_by_altitude() are its building blocks.

  • summarize_navigation() — heading convention and nav/attitude stats (NavigationSummary).

  • measure_ping_geometry() — ping spacing and resolution (PingGeometry).

  • detect_shadow_proposals() — object proposals from acoustic shadows and their highlights (ShadowProposals).
