    sidescanpy.export.windows.background¶

    Background (no-target) export windows.

    A detector trained only on target-centered images never sees an empty frame. :func:sample_background_windows samples window centers across a set of converted surveys, renders each one through the same window extractors as target windows (:func:~sidescanpy.export.windows.pixel.extract_pixel_style_window, :func:~sidescanpy.export.windows.geo.extract_geo_style_window), and keeps only windows that

    1. contain no cataloged target within the window plus margin_m. Every catalog target (any confidence) is correlated to its ping with :func:~sidescanpy.targets.correlate.correlate_target, projected onto every frequency of its file (:func:~sidescanpy.targets.correlate.place_catalog), and located in the rendered window with the same lookup target windows use for co-located targets. A conservative geographic guard additionally rejects a window whose reach from nadir (plus margin) covers any target's recorded lat/lon -- this catches targets on another file, another line crossing the same ground, or targets that never correlated;
    2. are mostly data: at most max_nan_frac of the rendered cells are NaN (outside coverage, nadir gap, cropped far range).

    Background windows are only as clean as the target catalog: an object the catalog misses can appear in one and be learned as background.

    2026 rshomberg@uri.edu

    WindowFootprint dataclass ¶

    Real-world extent of a rendered window.

    Attributes:

    Name Type Description
    frame str

    "pixel": rows are file pings, cols the style's column space (samples, or combined columns for dual swath). "geometric": rows along-track and cols across-track meters, in the loaded neighborhood's frame. "georef": rows northing and cols easting meters in the window's UTM zone.
    rows, cols tuple of float

    (min, max) bounds, before margin_m.
    reach_m float

    Upper bound on the distance from the center ping's nadir to any point of the window (used by the geographic guard).

    sample_background_windows ¶

    sample_background_windows(
    index: Mapping[Path, Mapping[str, Mapping]],
    catalog: Sequence[Target],
    spec: WindowSpec,
    n: int,
    rng: Generator,
    *,
    freq_keys: Sequence[str] | None = None,
    ping_ranges: Mapping[str, Sequence[tuple[int, int]]]
    | None = None,
    margin_m: float = 0.0,
    max_nan_frac: float = 0.3,
    max_match_dist_m: float = 25.0,
    n_draws: int = 1,
    max_attempts: int | None = None,
    candidates: Iterable[BackgroundCandidate] | None = None,
) -> list[BackgroundWindow]

    Sample, render and screen n background windows for one style.

    Candidates come from :func:sample_background_candidates (or from candidates), one at a time, until n are accepted or max_attempts are spent. A candidate is rendered n_draws times (independent jitter around the same center, as n_augment does for targets); it is accepted when its first draw passes, and each later draw is kept only if it passes too. A draw passes when it has no catalog target inside the window plus margin_m (the frame check and the geographic guard; see the module docstring) and at most max_nan_frac NaN cells.
