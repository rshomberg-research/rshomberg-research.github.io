    sidescanpy.export.ml.dataset¶

    Annotated training datasets of target-centered (and background) images.

    :func:build_target_dataset turns converted .ss.h5 surveys plus a target catalog into one COCO + YOLO dataset per export style, rendered at one render level and configured by a :class:DatasetSpec:

    1. Targets at or above min_confidence are correlated to their ping (:func:~sidescanpy.targets.correlate.correlate_target) and grouped by file and frequency.
    2. For each target a bounded ping neighborhood is loaded once and every style is cut from it n_augment times (independent jitter, optional random flip). Every catalog target inside a window becomes an annotation.
    3. Optionally, n_background screened no-target windows per style (:func:~sidescanpy.export.windows.sample_background_windows).
    4. Images are written as single-channel 8- or 16-bit PNGs, with targets.coco.json, a YOLO label set, augmentations.json (when draws vary) and a top-level manifest.json.

    Plotting (contact sheets, context views) is optional and supplied by the caller as callables, so this module never imports matplotlib.

    Output layout per style directory (layout="flat", the default)::

    <style>/target_<id>[_a<k>].png, bg_<n>[_a<k>].png
<style>/targets.coco.json
<style>/targets.yolo/{data.yaml,labels/<stem>.txt}
<style>/augmentations.json       (n_augment > 1, random_flip or backgrounds)
<style>/splits/{train,val}.txt   (val_fraction > 0)

    layout="ultralytics"::

    <style>/images/{train,val}/<file>.png
<style>/labels/{train,val}/<stem>.txt
<style>/{train,val}.coco.json
<style>/data.yaml                (Ultralytics dataset file)

    With several resolutions each gets its own res_<m>m/ directory.

    2026 rshomberg@uri.edu

    DatasetSpec dataclass ¶

    Everything that shapes a target dataset (defaults match sidescan-export chip).

    Attributes:

    Name Type Description
    styles tuple of str

    Subset of :data:~sidescanpy.export.windows.CHIP_STYLES.
    render_level str

    One of :data:~sidescanpy.export.windows.RENDER_LEVELS.
    size_px, swath_size_px int

    Output size of chip / the swath styles.
    resolution_m float, list of float, or None

    Geometric/georef meters per pixel; None chooses per window; a list builds one dataset per resolution under res_<m>m/.
    value_var str

    Geometric/georef (and pixel context) values: uncorrected, db or radiometric.
    resample_method, across_axis, swath_fill

    See :func:~sidescanpy.export.windows.extract_geo_style_window.
    box_size float

    Placeholder annotation box (pixels) for targets with no measured bbox.
    box_size_m (float, optional)

    Geometric/georef placeholder box in meters instead.
    with_context bool

    Write context/context_<id>.png views (needs a context callable).
    jitter_px, n_augment, random_flip

    Augmentation: center jitter, draws per target, random flips.
    gamma, pct_low, pct_high, normalization_scope, bit_depth

    Display transform (see :func:~sidescanpy.export.image.to_uint8).
    min_confidence str

    Targets below this are neither rendered nor annotated (backgrounds still avoid them).
    categories list of str, optional

    Fixed class order (see :func:~sidescanpy.export.ml.coco.resolve_categories).
    max_match_dist_m float

    Target-to-ping correlation distance.
    seed (int, optional)
    n_background, background_margin_m, background_max_nan_frac, background_ping_ranges

    Background windows (see :func:~sidescanpy.export.windows.sample_background_windows).
    val_fraction float

    Share of targets (by id hash) and background ping blocks put in the validation split; 0 disables splitting.
    split_block_pings int

    Background ping-block size for the split hash, so overlapping background windows share a split.
    layout str

    One of :data:LAYOUTS.
    frequencies list of str, optional

    Frequency keys (e.g. ["hz_900000"]) that target and background windows may come from. Default: every frequency in the files. Use it to keep a dead or unwanted channel out of the dataset; a target is otherwise matched to the frequency whose sample spacing is closest to its catalog's, which can be ambiguous when frequencies share a sample spacing.

    Whether the render level crops native sample/ping pixels.

    split_enabled property ¶

    split_enabled: bool

    Whether a validation split is assigned.

    build_target_dataset ¶

    build_target_dataset(
    sources: str | Path | Sequence[str | Path],
    targets: Sequence[Target],
    spec: DatasetSpec,
    out_dir: str | Path,
    *,
    contact_sheet: ContactSheetFn | None = None,
    context: ContextFn | None = None,
) -> DatasetResult

    Render a COCO + YOLO dataset of target (and background) images.

    Parameters:

    Name Type Description Default
    sources path or sequence of paths

    Directory of corrected .ss.h5 files, or the files themselves.

    		 required
    targets sequence of Target

    The whole catalog, any confidence: only targets at or above spec.min_confidence are rendered and annotated, but background windows avoid all of them.

    		 required
    spec DatasetSpec
    		required
    out_dir path
    		required
    contact_sheet callable

    Called once per style as contact_sheet(thumbnails, captions, *, boxes, box_size, suptitle, path) to draw a contact sheet (e.g. with :func:sidescanpy.viz.contact_sheet.contact_sheet).

    		 None
    context callable

    Called per target as context(image, target, *, coordinate_system, resolution_m, box_size, path) when spec.with_context.

    		 None

    Returns:

    Type Description
    DatasetResult

    Nothing is rendered when no target correlates (n_matched == 0).

    Raises:

    Type Description
    ValueError

    A target's category is missing from spec.categories.
