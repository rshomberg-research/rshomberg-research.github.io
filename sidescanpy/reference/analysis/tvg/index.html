    sidescanpy.analysis.tvg¶

    TVG analysis: backscatter-vs-range profiles and hardware-TVG detection.

    Profiles and comparisons:

    • :func:backscatter_vs_range, :func:backscatter_vs_sample — binned statistics (re-exported from :mod:sidescanpy.processing.profiles).
    • :func:compare_before_after — raw vs. TVG-corrected dB and the applied gain, side by side.
    • :func:bin_by_altitude — split pings into equal-count altitude bins.

    Detecting what TVG the data already carries:

    • :func:fit_tvg_curve — fit four single-term candidate loss models (flat, spreading_only, absorption_only, full_physics) to an observed loss-vs-range curve (:class:TVGCandidateFitResult).
    • :func:fit_range_decay — bin a dataset, fit the candidates and classify which terms hardware has already removed (:class:RangeDecayResult).

    TVGCandidateFit dataclass ¶

    One candidate loss model fit against an observed loss-vs-range curve.

    scale is the least-squares multiplier on the candidate's model (near 1: the data decays like that model as written; near 0: that term is essentially absent) and rmse_db its residual. fixed_scale_rmse_db is the residual with the scale pinned to 1 — the literal physics model. Candidates are ranked by the fixed-scale value, because a free scale on one term can absorb unrelated range-dependent effects and win on RMSE alone. For flat (model identically zero) both values are equal.

    TVGCandidateFitResult dataclass ¶

    All four candidate fits for one curve, plus the best by fixed-scale RMSE.

    RangeDecayResult dataclass ¶

    Bases: ResultMixin

    TVG-status classification from a range-decay fit.

    tvg_status names what hardware has already removed: "none", "spreading_only", "absorption_only", "full", or "ambiguous" (winner not clearly ahead, or too little data). best_rmse_db is the winner's fixed-scale RMSE (the ranking criterion); best_free_fit_* are its free-scale values. r_ref_m_override / r_fit_min_m_override record what was requested (e.g. "auto"); r_ref_m / r_fit_min_m what was used. fit (the full :class:TVGCandidateFitResult) is left out of to_dict(); candidates summarizes it.

    fit_tvg_curve ¶

    fit_tvg_curve(
    binned: DataFrame,
    *,
    spreading_loss_db: float = DEFAULT_SPREADING_LOSS_DB,
    absorption_db_per_m: float,
    r_ref_m: float | None = None,
    r_fit_min_m: float | None = None,
    r_fit_max_m: float | None = None,
    min_count_for_r_ref: int = 30,
    fit_fraction: float = 0.6,
    r_ref_search_fraction: float = 0.5,
    value_col: str = "mean",
) -> TVGCandidateFitResult

    Fit four candidate hardware-TVG models to a binned raw dB-vs-range curve.

    Each candidate is a term (or both) of :func:~sidescanpy.processing.radiometric.tvg_gain_db still present in the data:

    • flat — neither term (hardware compensated both)
    • spreading_only — only spreading_loss_db * log10(R)
    • absorption_only — only 2 * absorption_db_per_m * R
    • full_physics — both (no hardware compensation)

    The fitted quantity is observed_loss(r) = value[r_ref] - value[r] (absolute level is unknown). Each candidate gets one free scale, fitted independently: a joint two-term regression is poorly conditioned because the terms are nearly collinear over realistic range spans.

    Parameters:

    Name Type Description Default
    binned DataFrame

    :func:backscatter_vs_range output computed on uncorrected dB backscatter.

    		 required
    spreading_loss_db float

    Spreading coefficient of the spreading_only and full_physics candidates (:data:~sidescanpy.processing.radiometric.DEFAULT_SPREADING_LOSS_DB).

    		 30.0
    absorption_db_per_m float

    Required; pass the survey's own frequency-appropriate value.

    		 required
    r_ref_m float

    Reference range. Default: the bin with the highest value among bins with count >= min_count_for_r_ref in the near r_ref_search_fraction of the range span (falls back to all eligible bins). Not simply the nearest bin, which often reads low from ring-down/blanking; not the global max, which on flat data can land on a far-range noise bump.

    		 None
    r_fit_min_m float

    Near edge of the fit window. Default r_ref_m (one-sided). Set it lower to fit both sides of the reference.

    		 None
    r_fit_max_m float

    Far edge of the fit window. Default r_ref_m + fit_fraction * (max_range - r_ref_m).

    		 None
    min_count_for_r_ref int
    		30
    fit_fraction float
    		0.6
    r_ref_search_fraction float
    		0.5
    value_col (mean, median)

    Per-bin statistic to fit.

    		 "mean"

    Returns:

    Type Description
    TVGCandidateFitResult

    Raises:

    Type Description
    ValueError

    If binned is empty, or no bin has count >= min_count_for_r_ref.

    fit_range_decay ¶

    fit_range_decay(
    ds: Dataset,
    value_var: str = "backscatter_intensity",
    range_var: str = "slant_range_m",
    *,
    already_db: bool = False,
    db_reference_percentile: float = 99.0,
    db_reference_value: float | None = None,
    freq_hz: float | None = None,
    bin_width_m: float = 5.0,
    usable_range_m: float | None = None,
    min_bins: int = 6,
    ambiguous_rel_tol: float = 0.2,
    min_total_count: int = 30,
    exclude_before_sample: ndarray | None = None,
    exclude_first_n_bins: int = 0,
    reject_outliers: bool = False,
    outlier_mad_k: float = 3.5,
    outlier_min_bin_count: int = 5,
    fit_value_col: str = "mean",
    r_ref_m: float | str | None = None,
    r_fit_min_m: float | str | None = None,
    r_fit_min_auto_margin_m: float = _AUTO_NEAR_EDGE_MARGIN_M,
    r_ref_search_fraction: float = 0.5,
    r_ref_window_fraction: float = 1.0 / 3.0,
    channel: int | str | None = None,
    spreading_loss_db: float = DEFAULT_SPREADING_LOSS_DB,
) -> RangeDecayResult

    Classify which TVG terms value_var already carries.

    Converts to dB, bins by range_var, fits the four :func:fit_tvg_curve candidates and maps the winner (lowest fixed-scale RMSE) to a TVG status. If the runner-up's RMSE is within ambiguous_rel_tol (relative) of the winner's, the status is "ambiguous".

    Water-column samples are always excluded via ground_range_m's NaN pattern (when present), independent of range_var.

    dB reference

    Without calibration an absolute dB level is arbitrary, so linear values are converted relative to the data's own db_reference_percentile (or db_reference_value). Every fit quantity is a dB difference, so this choice does not change the classification.

    Parameters:

    Name Type Description Default
    range_var str

    Range axis; slant range matches apply_tvg's gain model.

    		 "slant_range_m"
    already_db bool

    value_var is already dB; skip the conversion.

    		 False
    db_reference_percentile float
    		99.0
    db_reference_value float

    Exact linear reference instead of the percentile (e.g. 1.0 for "dB re 1").

    		 None
    freq_hz float

    Default: the channel's center frequency (:func:~sidescanpy.processing.radiometric.center_frequency_hz); sets the absorption term.

    		 None
    bin_width_m float

    Requested bin width; shrunk (never widened) so that usable_range_m spans at least min_bins bins.

    		 5.0
    usable_range_m float

    Far edge of the fit window.

    		 None
    min_bins int
    		6
    min_total_count int

    Fewer binned samples than this → "ambiguous" without a fit.

    		 30
    exclude_before_sample ndarray

    (ping, channel) sample index; samples before it are dropped (in dB space) before binning. For aggregate fits pass a uniform boundary (:func:~sidescanpy.processing.bottom.uniform_exclusion_boundary): a per-ping one biases the near-range bins and the reference pick.

    		 None
    exclude_first_n_bins int

    Drop this many nearest bins after binning, before the reference pick and fit — for a bright leading-edge artifact at the bottom return.

    		 0
    reject_outliers bool

    Run :func:~sidescanpy.processing.outliers.reject_range_outliers on the dB values first (outlier_mad_k, outlier_min_bin_count).

    		 False
    fit_value_col (mean, median)

    Passed to :func:fit_tvg_curve as value_col.

    		 "mean"
    r_ref_m (float, auto, mid_swath or None)

    Reference range. None: :func:fit_tvg_curve's near-field auto-pick. "auto" (recommended with r_fit_min_m="auto"): placed r_ref_window_fraction of the way from the resolved fit window's near edge to usable_range_m, so it always lies inside the window. "mid_swath" (legacy): usable_range_m / 2. Both string modes fall back to the auto-pick, with a note, when usable_range_m is unavailable.

    		 None
    r_fit_min_m (float, auto or None)

    Near edge of the fit window (resolved before r_ref_m). None: one-sided from r_ref_m. "auto": the raw near-field peak bin's far edge plus r_fit_min_auto_margin_m, searched up to a numeric r_ref_m or r_ref_search_fraction * usable_range_m; falls back to None with a note when it can't be resolved. If it ends up beyond a numeric/"mid_swath" r_ref_m it is clamped to it.

    		 None
    r_fit_min_auto_margin_m float
    		5.0
    r_ref_search_fraction float
    		0.5
    r_ref_window_fraction float
    		1/3
    channel int or str

    Restrict to one physical side (index or channel_id value). None pools both. Applied by masking.

    		 None
    spreading_loss_db float

    Spreading coefficient of the spreading_only and full_physics candidates; pass the value the survey's correction uses.

    		 30.0
