sidescanpy.io.humminbird.reader#

Read Humminbird side imaging recordings (.DAT + .SON).

A recording is a small RNNNNN.DAT (or RecNNNNN.DAT) file and a directory of the same name holding one B00n.SON file per beam (and a B00n.IDX index, which is not needed here). Humminbird publishes no specification; the layout below follows the open readers PyHum and PINGVerter (PING-Mapper) and was checked on Helix recordings.

.DAT (read_dat())

One header for the recording: water type, start time (Unix seconds), first position, the recording name, ping count and duration. Three layouts are known, told apart by file size: 64 bytes, big-endian (Helix and older units, the one tested); 96 and 100 bytes, little-endian (Solix, laid out as in PINGVerter, untested). Onix units write an XML .DAT, which is not read.

.SON (read_son())

A sequence of ping frames. Each frame starts with the 4 bytes C0 DE AB 21, then a run of tagged big-endian fields: a 1-byte tag followed by a 1-byte value when the tag’s top bit is clear (tags 80-87) or a 4-byte value when it is set (tags 128-160). Tag 160 is the number of samples; the byte 0x21 ends the header; that many 8-bit samples follow. Headers are 67 bytes on older Helix files and 72 or 152 bytes on newer ones: the set of tags differs, the encoding does not, so the tags are decoded generically. Known tags are named in TAG_NAMES; others are kept as tag_<n>.

Positions (tags 130 and 131) are easting and northing in metres on a spherical Mercator projection with the International 1924 radius (6 378 388 m), the convention PyHum and PINGVerter use; humminbird_to_lonlat() converts them.

The reader returns the fields as recorded (tenths of a degree, decimetres); sidescanpy.io.humminbird.converter converts units and pairs the port and starboard beams.

sidescanpy.io.humminbird.reader.read_son(path)#

Read every ping frame of one .SON file.

A frame cut short by the end of the file is dropped and counted in n_truncated. Bytes that do not start a frame where one is due are skipped to the next frame start, counted in n_resyncs and logged at WARNING.

Raises:
ValueError

If the file holds no ping frame, or its frames disagree on the beam number.

sidescanpy.io.humminbird.reader.humminbird_to_lonlat(easting, northing)#

Humminbird Mercator easting / northing (m) to WGS84 longitude / latitude (degrees).

The positions are on a sphere of radius MERCATOR_RADIUS_M; the latitude formula (from PyHum and PINGVerter) inverts the Mercator northing to geocentric latitude and converts that to geodetic latitude with the factor 1.0067642927.
