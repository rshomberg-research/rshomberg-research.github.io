    sidescanpy.grids.geotiff¶

    GeoTIFF output for gridded rasters.

    :func:to_geotiff writes one variable of a :class:SideScanGriddedRaster (or of the plain dataset from its to_dataset()) as a single-band, north-up GeoTIFF with CRS, affine transform and nodata, via rioxarray. rioxarray is the optional geo extra (pip install sidescanpy[geo]) and is imported only here, only when called.

    to_geotiff ¶

    to_geotiff(
    raster: SideScanGriddedRaster | Dataset,
    path: str | Path,
    *,
    variable: str = "backscatter",
    dtype: str = "float32",
    nodata: float = float("nan"),
    compress: str | None = "deflate",
) -> Path

    Write variable of a gridded raster as a single-band GeoTIFF.

    Parameters:

    Name Type Description Default
    raster SideScanGriddedRaster or Dataset

    A raster, or the dataset from SideScanGriddedRaster.to_dataset() (1-D y/x cell-center coordinates plus a CF spatial_ref coordinate holding the CRS).

    		 required
    path str or Path

    Output .tif path; parent directories must exist.

    		 required
    variable str

    Data variable to write (e.g. "n_contributing_samples").

    		 "backscatter"
    dtype str

    Output band dtype.

    		 "float32"
    nodata float

    Nodata value recorded in the file; NaN cells are written as this.

    		 NaN
    compress str or None

    GDAL compression creation option; None for uncompressed.

    		 "deflate"

    Returns:

    Type Description
    Path

    path.
    Notes

    Rows are flipped to north-up. The affine transform is built from the real cell centers (pixel size = center spacing), which is approximately, not exactly, resolution_m -- see SideScanGriddedRaster.to_dataset. The variable's attrs (units, long_name, ...) and the raster's channel/processing attrs are written as GeoTIFF tags.

    Raises:

    Type Description
    ImportError

    If rioxarray is not installed (geo extra).
    KeyError

    If variable is not in the dataset.
