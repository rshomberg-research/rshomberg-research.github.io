sidescanpy.datasets#

Openly licensed sidescan recordings for examples and tests.

Each registered file is one raw recording, or one published product made from recordings, in a public agency archive. Most archives are multi-gigabyte zips: fetch() pulls just the one member out with HTTP range requests, so an example needs a few tens of megabytes instead of the whole archive. A few archives serve each file on its own URL; those are downloaded directly. Either way the SHA-256 is checked and the file cached.

>>> from sidescanpy import datasets
>>> path = datasets.fetch("jncc_wight_barfleur_20130321174522.jsf")
>>> print(datasets.citation("jncc_wight_barfleur_20130321174522.jsf"))

The cache is SIDESCANPY_DATA_DIR when set, otherwise ~/.cache/sidescanpy ($XDG_CACHE_HOME/sidescanpy if that is set). A file already in the cache with the right checksum is used as is, so a directory of pre-downloaded files works offline.

Only standard-library modules are used. Downloads log at DEBUG; call sidescanpy.log.configure_logging() with "DEBUG" to see them.

sidescanpy.datasets.BGS_LONDON_GATEWAY_WRECKS#

Catalogued wreck centres of the London Gateway survey, as given in the BGS record (UTM zone 31N, WGS84; easting, northing in meters). Centres only: a line can show its wreck tens of meters away along track, so treat them as approximate positions, not boxes.

sidescanpy.datasets.fetch(name, *, directory=None)#

Return a local path to a registered recording, downloading it if needed.

Parameters:
namestr

A name from list_datasets().

directorystr or Path, optional

Where to look for and store the file. Defaults to data_dir().

Returns:
Path

The verified local file.

Raises:
KeyError

If name is not registered.

OSError

If the download fails or the downloaded file’s size or SHA-256 does not match the registry, after two retries (5 s and 20 s apart, each logged as a WARNING). The partial file is removed.
