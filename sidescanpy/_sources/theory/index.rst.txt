Theory
======

Why sidescan imagery looks the way it does. Each page takes one idea:
it states the physics, with the formula and a diagram, then measures
the idea on a real, openly licensed recording, so every number can be
checked.

The :doc:`/examples/index` show how to do a task with sidescanpy; these
pages explain the physics behind the steps.

Every page is a script in ``examples/theory/`` that runs when this site
is built, on the recordings listed in :doc:`/example_data`. Run one
yourself with an output directory::

    python examples/theory/plot_shadow_height.py out/

    <div class="sphx-glr-thumbcontainer" tooltip="A sidescan file holds numbers, one per sample, that rise and fall with the echo. They are relative: the receiver amplifies the transducer&#x27;s voltage and a digitizer turns it into integers, so each number is proportional to the echo&#x27;s voltage at that point in the receiver. Nothing in the file ties those numbers to sound pressure in micropascals; that needs a calibration of the transducer and receiver, which ordinary surveys do not carry. Only ratios between samples mean something.">
